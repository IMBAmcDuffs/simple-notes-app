# Design Templates

**MANDATORY**: Downstream developers MUST use the scaffold in this directory
as the implementation source of truth. All design decisions, component structures,
and brand guidelines in `stitch/` are the approved deliverables.

## Generated Devices

desktop, mobile

## Structure

- `stitch/manifest.json` — Structured metadata (project IDs, screen IDs, URLs)
- `stitch/design-brief.md` — Approved design brief
- `stitch/brand-guidelines.md` — Theme and branding guidance
- `stitch/<device>/` — Device-specific scaffold and references
